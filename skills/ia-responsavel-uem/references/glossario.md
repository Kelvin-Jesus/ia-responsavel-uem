# Glossário e referências (guia, seção 19)

Use estes termos com estes sentidos em toda explicação.

- **IA generativa** — tipo de IA que cria conteúdo novo (texto, imagem, código, áudio) a partir de um pedido.
- **Prompt** — o pedido ou a instrução escrita para a ferramenta.
- **Alucinação** — resposta inventada pela IA, como dados ou referências que não existem.
- **Viés** — distorção que favorece ou prejudica grupos ou ideias, herdada dos dados de treinamento.
- **Dado pessoal** — informação que identifica uma pessoa, como nome, CPF ou foto.
- **Dado sensível** — dado sobre saúde, origem racial, religião, opinião política, biometria e outros (LGPD).
- **Anonimização** — retirar do dado tudo o que permite identificar a pessoa.
- **DOI** — código que identifica um artigo de forma única e leva ao texto original.
- **Ineditismo** — condição de um resultado ainda não divulgado, essencial para publicar e patentear.
- **LGPD** — Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018).
